# Tic-Tac-Toe
# 🎮 Tic Tac Toe Game (JavaScript)

A simple, interactive Tic Tac Toe game built using **HTML, CSS, and JavaScript**.  
The project focuses on clean architecture using **factory functions and the module pattern (IIFE)**.

---

## 🚀 Features

- 🎯 Two-player gameplay (Player X vs Player O)
- ✍️ Custom player name input
- 🔄 Restart game functionality
- 🏆 Win detection (rows, columns, diagonals)
- 🤝 Tie detection
- 🖥️ Fully interactive UI
- 🎨 Clean, responsive design

---

## 🧠 Project Structure

The project is built using modular JavaScript design:

### 🧩 Gameboard Module
- Stores the game state (array)
- Handles updates and resets

### 👤 Player Factory
- Creates player objects with name and marker

### 🎮 GameController Module
- Controls game flow
- Handles turns, win logic, and game state

### 🖼️ DisplayController Module
- Handles DOM rendering
- Manages user interaction
- Updates UI based on game state

## 🎮 How to Play

1. Enter player names
2. Click **Start Game**
3. Players take turns clicking the board
4. First player to align 3 marks wins
5. Click **Restart** to play again
